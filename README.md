# 🛡️ WebSentinel

**WebSentinel** is an automated web security assessment tool built with Python.

It analyzes websites for common security misconfigurations and provides security findings, severity levels, an overall assessment score, and an HTML security report.

> ⚠️ WebSentinel is intended for educational purposes and authorized security assessments only. Only scan websites and systems that you own or have explicit permission to test.

---

## 📌 About

WebSentinel helps security learners and developers quickly identify common web-security configuration issues.

The tool performs automated checks across multiple areas of web security and presents the results in an easy-to-understand format.

### 🔍 What WebSentinel Checks

- HTTP Security Headers
- Content Security Policy (CSP)
- Cookie Security
- HTTPS / TLS configuration
- CORS configuration
- DNS security
- Subdomain security
- HTTP methods
- Technology information
- Exposed files
- Security.txt
- Common web misconfigurations
- Server information disclosure
- Security-related configuration issues

# ✨ Features

| Feature | Description |
|---|---|
| 🔐 Security Headers | Checks important HTTP security headers |
| 🛡️ CSP Analysis | Analyzes Content Security Policy configuration |
| 🍪 Cookie Analysis | Checks cookie security attributes |
| 🔒 HTTPS/TLS | Performs HTTPS and TLS-related checks |
| 🌐 CORS | Checks Cross-Origin Resource Sharing configuration |
| 📡 DNS Security | Performs DNS-related security checks |
| 🔎 Subdomains | Supports subdomain security assessment |
| ⚙️ HTTP Methods | Checks available HTTP methods |
| 📦 Technology Detection | Identifies technology information exposed by a website |
| 📁 Exposed Files | Checks for commonly exposed files |
| 📄 Security.txt | Checks for security contact information |
| 📊 Security Score | Generates an automated assessment score |
| 🚨 Severity Findings | Organizes findings by severity |
| 📑 HTML Report | Generates a readable HTML security report |
| 🖥️ JSON Output | Supports JSON output |
| 🔴 Active Mode | Provides authorized active assessment functionality |
| 🟢 Passive Mode | Performs passive security assessment |
